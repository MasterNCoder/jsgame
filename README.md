Welcome to JsGame. 

JsGame is a JavaScript module designed to help the writing of Canvas code to go smoother, faster, and easier. The JsGame module largely removes asyncronus event handling to help people familiar with syncronated event processing.

Currently, there is no documentary beyond what you can find here. Documentary may be written once the project is closer to complete. 
However, the code is fairly readable and understandable, so those with some coding experience may find enough information just within the code itself.
